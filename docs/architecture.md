# Математическая модель ядра Risk Engine

Система производит инкрементальный пересчет ликвидности в режиме реального времени на основе следующих финансовых метрик:

## 1. Коэффициент абсолютной ликвидности (Кал)
Показывает, какую часть краткосрочной задолженности компания может погасить немедленно.
$$К_{ал} = \frac{\text{Денежные средства (Current Balance)}}{\text{Краткосрочные обязательства}}$$
* **Норматив в системе:** $K_{ал} \ge 0.2$. При падении ниже 0.2 генерируется `SystemAlert` уровня `WARNING`.

## 2. Прогнозирование кассового разрыва (Cash Flow Forecast)
Прогнозный баланс счета ($B_{forecast}$) на день $t$ рассчитывается по формуле:
$$B_{forecast}(t) = B_{current} + \sum_{i=1}^{t} IN_i - \sum_{i=1}^{t} OUT_i$$
Где:
* $B_{current}$ — текущий остаток на счете из таблицы `accounts`.
* $IN_i$ — плановые поступления на день $i$.
* $OUT_i$ — плановые списания на день $i$.

Если $B_{forecast}(t) < 0$, система фиксирует риск кассового разрыва и создает алерт уровня `CRITICAL`.
